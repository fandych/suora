# Chat

Chat 是日常对话、工具协作、附件处理和流水线命令的主执行面。

## 什么时候先打开它

- 你已经至少有一个可用模型
- 你准备开始真实任务，而不是继续配环境
- 你要看工具调用、重试或分支对话

## 当前能力面

- 多会话与标签
- 会话级模型和 Agent 切换
- 文件、图片和音频附件
- 流式输出与工具调用可视化
- 重试、编辑、置顶、分支和朗读
- `/pipeline` 命令联动

## 常和哪些模块一起用

- Models 负责 provider 和模型可用性
- Agents 负责角色与工具边界
- Documents 提供上下文资料
- Pipeline 提供可复用工作流
