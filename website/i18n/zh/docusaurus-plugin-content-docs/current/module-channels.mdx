# Channels

Channels 把消息平台和邮箱流量接入工作台，并把入站消息路由给指定回复 Agent。

## 什么时候先打开它

- Suora 需要从桌面之外接收任务
- 某个回复 Agent 要服务特定平台或人群
- 你需要 Webhook、Stream 或 Email 路由

## 当前能力面

- Webhook 与 Stream 两类传输
- 回复 Agent 绑定与白名单
- 消息、用户、健康和调试面板
- 支持微信、飞书、钉钉、Slack、Telegram、Discord、Teams、Email 和自定义渠道

## 常和哪些模块一起用

- Agents 负责回复行为
- Models 负责下游 AI 执行
- Settings 与 Logs 负责运行安全和诊断
