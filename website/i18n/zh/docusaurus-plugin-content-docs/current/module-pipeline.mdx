# Pipeline

Pipeline 把多步 Agent 任务保存成可重复执行的工作流，并提供历史与执行控制。

## 什么时候先打开它

- 一个手工流程已经重复出现多次
- 你需要步骤级重试、条件或变量传递
- 你想让 Chat 或 Timer 以后直接触发它

## 当前能力面

- 多步已保存工作流
- 步骤 Agent、重试、超时和 `runIf`
- 变量导出与预算控制
- dry run 与执行历史
- Mermaid 预览和导入导出

## 常和哪些模块一起用

- Agents 负责各步骤执行
- Chat 负责命令式触发
- Timer 负责定时触发
