# Documents

Documents 是本地知识工作区，负责文档组、文件夹、回链、图谱和可带入聊天的上下文。

## 什么时候先打开它

- 任务依赖长期资料，而不是一次性提示词
- 你要把笔记做成稳定结构，而不是只在 Chat 里堆上下文
- 你要看回链、图谱或知识健康度

## 当前能力面

- 文档组与嵌套文件夹
- 支持 Mermaid 与数学公式的 Markdown 编辑
- 回链、引用和图谱洞察
- 搜索与相关笔记扩展
- 文档到 Chat 的上下文选择

## 常和哪些模块一起用

- Chat 用来消费文档上下文
- Agents 可帮助创建和修订文档
- Settings 影响工作区和知识相关行为
