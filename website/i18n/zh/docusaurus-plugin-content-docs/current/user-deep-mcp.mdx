# MCP 深挖

当工作台需要外部协议能力，而核心问题其实是 transport、scope 和信任边界时，从这里继续往下读。

## 重点

- workspace scope 与 user scope
- `stdio`、`http`、`sse`、`ws` 的适用性
- env、args 与 headers 的最小化配置
- status 与 Agent 可见性的区别
- 服务信任与能力边界治理
