# Agents

Agents 把角色、提示词、模型偏好、技能、记忆和工具权限包装成可复用执行单元。

## 什么时候先打开它

- 角色质量比一次性提示词更重要
- 你总在重复同样的输出规则和工具边界
- 你需要测试或版本化一个可复用助手配置

## 当前能力面

- 内置与自定义 Agent
- 提示词、模型和技能编辑
- 工具白名单与黑名单
- 测试、复制、导入导出和快照

## 常和哪些模块一起用

- Chat 负责实时执行
- Skills 负责复用领域行为
- Pipeline、Timer 和 Channels 负责自动化归属
