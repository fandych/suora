# MCP

MCP 用来配置外部 Model Context Protocol 服务，让 Agent 可以调用超出内置工具面的能力。

## 什么时候先打开它

- 内置工具和普通技能已经不够
- Agent 需要协议化的外部服务能力
- 你需要工作区级或用户级的服务配置

## 当前能力面

- `stdio`、`http`、`sse`、`ws` 四类服务配置
- scope、环境变量、请求头和参数管理
- 连接测试与状态跟踪

## 常和哪些模块一起用

- Agents 负责实际消费这些能力
- Chat 负责任务执行
- Settings 负责共享运行前提和安全边界
