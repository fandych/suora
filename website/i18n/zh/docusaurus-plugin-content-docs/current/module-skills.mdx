# Skills

Skills 管理基于 `SKILL.md` 的能力包、注册表来源、导入导出和共享目录。

## 什么时候先打开它

- 多个 Agent 需要共享同一套领域规则
- 你要导入、发布或维护能力包
- 你要接入共享技能目录

## 当前能力面

- 已安装技能管理
- 来源过滤和外部目录
- `SKILL.md` 编辑与资源树
- 注册表浏览与导入导出

## 常和哪些模块一起用

- Agents 负责组合技能行为
- Settings 负责外部目录加载
- Documents 可为技能提供附带参考资料
