# Models

Models 负责 provider 配置、模型启用、连接测试和比较视图。

## 什么时候先打开它

- 任意 AI 功能无法正常调用模型
- 你要新增 provider 或本地端点
- 你要比较模型再决定绑定策略

## 当前能力面

- provider 配置与预设
- provider 下模型启用
- 连接测试
- compare 视图

## 常和哪些模块一起用

- Chat 负责真实任务执行
- Agents 负责默认模型路由
- Pipeline 与 Timer 受成本和稳定性影响
