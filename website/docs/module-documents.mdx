# Documents

Documents is the local knowledge workspace for note groups, folders, backlinks, graph views, and chat-ready context.

## Open Documents when

- the task depends on durable source material
- you want structured local notes instead of prompt-only context
- you need backlinks, graph inspection, or note health signals

## Current surface

- document groups and nested folders
- markdown editing with Mermaid and math support
- backlinks, references, and graph insights
- search and source-aware related-note expansion
- document-to-chat context selection

## Works closely with

- Chat for context injection
- Agents for document editing flows
- Settings for workspace and knowledge-related behavior
