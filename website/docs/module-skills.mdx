# Skills

Skills manages `SKILL.md`-based capability packages, registry sources, imports, exports, and shared directories.

## Open Skills when

- several agents need the same domain instructions
- you want to import or publish a reusable capability package
- you need to manage shared skill directories

## Current surface

- installed-skill management
- source filters and external directories
- `SKILL.md` editing and resource trees
- registry browsing plus import or export

## Works closely with

- Agents for behavior composition
- Settings for external directory loading
- Documents when a skill ships bundled reference material
