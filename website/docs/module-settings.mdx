# Settings

Settings is the global control plane for appearance, security, data handling, automation, extensions, logs, and system state.

## Open Settings when

- behavior needs to change across the workspace, not just in one screen
- you need to review security or storage boundaries
- logs, diagnostics, or shared directories matter to the task

## Current surface

- `general`, `security`, `voice`, `shortcuts`, `data`, `knowledge`, `events`, `external-dirs`, `plugins`, `logs`, and `system`
- workspace preferences and safety controls
- data import, export, and cleanup
- logs, diagnostics, and onboarding replay

## Works closely with

- Models for secure key handling
- Skills and Agents for external directory loading
- Channels and MCP for runtime safety and diagnosis
