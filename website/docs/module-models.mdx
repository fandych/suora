# Models

Models manages provider configuration, model enablement, connectivity testing, and compare views.

## Open Models when

- any AI-facing feature cannot reach a model
- you need to add a provider or local endpoint
- you want to compare model choices before binding them elsewhere

## Current surface

- provider setup and presets
- model enablement per provider
- connection testing
- compare view for model selection

## Works closely with

- Chat for real task execution
- Agents for default model routing
- Pipeline and Timer for automation costs and reliability
