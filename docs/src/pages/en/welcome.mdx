## Documentation scope

- **User docs** focus on product usage, including models, agents, workflows, integrations, and channels.
- **Technical docs** focus on implementation structure, runtime boundaries, quality checks, and release workflows.

## Suggested reading path

If this is your first time using SUORA, read in this order:

1. **Installation & Startup**: get the environment ready and configure your first model.
2. **Chats / Models / Agents**: learn the core conversation, model selection, and agent workflow.
3. **Documents / Skills / Integrations**: add knowledge sources, reusable guidance, and external capabilities.
4. **Workflows / Schedulers / Channels**: move on to automation, scheduled execution, and external message entry points.

If you are maintaining the app or planning implementation changes, start with:

- **Architecture**
- **IPC**
- **SQLite Data Layer**
- **Testing & Release**
- **Security Guardrails**

<Callout type="warning">
  API keys, channel credentials, and SMTP passwords are sensitive data. Only enable agent tools, workflow scripts, or public webhooks in trusted workspaces and on trusted devices.
</Callout>
