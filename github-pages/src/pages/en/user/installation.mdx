# Installation & Startup

SUORA is an Electron desktop app. The development environment requires Node.js `>= 22.12.0` and npm.

## Install dependencies

```bash
git clone https://github.com/fandych/suora.git
cd suora
npm ci
npm run dev
```

If you must disable Chromium sandboxing, use `npm run dev:root`. If Electron binaries fail to download, run `npm run electron:download`.

## Configure the first model

1. Open **Models** after the app starts.
2. Pick a preset provider, or create a Custom / OpenAI-compatible provider.
3. Fill in the Base URL, API key, and enable at least one model. Ollama, Custom, and OpenRouter can work without an API key when the endpoint allows it.
4. Open **Chats** and start a test conversation with the selected model or agent.
