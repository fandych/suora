# 安装与启动

SUORA / 朔枢 是 Electron 桌面应用。开发环境需使用 Node.js `>= 22.12.0` 和 npm。

## 获取最新发布包

如果你想直接安装桌面应用，而不是从源码启动开发环境，请前往 GitHub Release 下载打包产物。

- 当前文档核对的最新公开版本是 <a href={docsSiteMetadata.latestRelease.url} target="_blank" rel="noreferrer">{docsSiteMetadata.latestRelease.tagName}</a>（发布于 {formatReleasePublishedAt("zh")}）。
- 发布页会提供该版本实际上传的 Windows、macOS 与 Linux 安装包或便携产物。
- 仓库主页与文档入口分别位于 <a href={docsSiteMetadata.repository.url} target="_blank" rel="noreferrer">{docsSiteMetadata.repository.url}</a> 和 <a href={docsSiteMetadata.repository.homepageUrl} target="_blank" rel="noreferrer">{docsSiteMetadata.repository.homepageUrl}</a>。

## 安装依赖

```bash
git clone https://github.com/fandych/suora.git
cd suora
npm ci
npm run dev
```

如果在 root 或必须关闭 Chromium sandbox 的环境中启动，请运行 `npm run dev:root`。Electron 二进制下载失败时，可执行 `npm run electron:download`。

## 配置第一个模型

1. 启动应用后进入 **模型**。
2. 选择预设提供商，或创建一个 Custom / OpenAI-compatible 提供商。
3. 填写 Base URL、API Key，并启用至少一个模型。Ollama、Custom 和 OpenRouter 可按端点要求不填写 API Key。
4. 打开 **聊天**，选择模型或智能体后开始对话。
