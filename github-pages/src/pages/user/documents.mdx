# Documents

Documents 是 SUORA 的本地文档工作区。每个文档包含名称、简介和页面/资源树，可用于编写 Markdown、保存参考资料，并作为 Agent 或 workflow 的知识来源。

## 创建文档

1. 进入 **Documents**，选择新建文档。
2. 填写名称和简介，创建后会进入文档详情页。
3. 在左侧树中添加文件、文件夹或上传已有资源。
4. 选择文本页后开始编辑；更改会自动保存。

文档列表按最近更新时间排序。新建文档会创建草稿版本和默认页面树。自动保存会将名称、简介、页面内容、树结构和设置一起写入本地快照，通常在最后一次修改约 900 ms 后执行。

## 管理页面与文件夹

文档以树形结构组织：节点可以是文本/资源文件或文件夹。每个文件夹的菜单和右键菜单提供新建文件、新建子文件夹、上传、导出、重命名和删除。

- 新建文本页默认包含 `# New Document`。
- 无扩展名的普通文件会自动补为 `.md`。
- 同名文件会自动加上 `-2`、`-3` 等后缀。
- 删除文件夹会递归删除其子节点。
- 文档树至少保留一个节点，最后一个节点不能从界面删除。
- 删除整个文档会删除所有版本，无法撤销。

<Callout>
  当前界面没有拖放、移动或剪切粘贴页面功能。创建或上传时可选择目标文件夹；需要重新组织时，可新建目标文件并复制内容后再删除原文件。
</Callout>

## 编辑文本内容

Markdown、MDX、TXT 和无扩展名页面可在 **富文本** 与 **源码** 模式之间切换。JSON、YAML、TypeScript、JavaScript、HTML 等文件使用 Monaco 源码编辑器，并按扩展名提供对应语法模式。

富文本编辑器保存为 Markdown，支持：

- 段落、H1–H6、粗体、斜体、删除线、行内代码、引用、分割线和代码块。
- 无序列表、有序列表和任务清单。
- 表格：插入表头表格、添加行或列、调整列宽。
- KaTeX 行内和块级公式。
- Mermaid 图的编辑与 SVG 预览。
- Markdown 链接、图片语法，以及 `[[页面名]]` 内部链接语法。

## 编辑器限制

- 工具栏没有图片上传、插入链接、撤销/重做或删除表格行列的专用按钮。
- 图片可在源码中写入 `![说明](url)`；也可先上传资源，再手写引用路径或 data URL。
- Markdown 转换器是轻量实现，复杂嵌套、复杂表格和原始 HTML 的往返保真不作保证。
- `[[页面名]]` 会被渲染为内部锚点，但当前没有点击后自动定位对应页面的功能。
- Documents 不提供实时协作、评论、修订、共享权限或冲突合并。

## 上传与资源预览

可在任意文件夹中一次选择多个本地文件：

- Markdown、JSON、YAML、HTML、CSV、TS/JS、Python、Shell、SQL 等文本格式会按文本读入。
- 其他格式以 base64 `data:` URL 保存到文档树。
- 图片、视频和音频资源可在详情页预览或播放。
- PDF 和其他二进制资源目前会显示“不能作为文本编辑”的提示。

上传的资源就是文档树节点，不存在独立“附件列表”。

<Callout type="warning">
  Documents 上传目前没有专用的单文件大小、总大小、数量或 MIME 限制。文件会读入应用内存并存入本地 SQLite；避免导入大视频、安装包或其他大型二进制文件，以免影响保存速度和数据库体积。
</Callout>

## 导出与导入

- 导出单个文件时会下载原始内容；没有扩展名时按 `.md` 命名。
- 导出文件夹时会生成该文件夹及全部子项的 JSON 数组，**不是 ZIP 文件**。
- 数据层具备 ZIP 导入预览、`overwrite` / `skip` / `rename` 冲突策略和路径穿越保护，但当前 Documents 页面尚未提供 ZIP 导入入口。

在分享导出文件前，请检查是否含有 API 响应、客户资料、密码或其他敏感信息。

## 作为 Agent 知识来源

可在 Agent 的 Documents 绑定区选择需要的文档。Chat 中的 Agent 会在所绑定范围内按标题检索并返回摘要；未绑定任何文档时，当前实现允许搜索全部 Documents。

搜索是本地关键词包含匹配，不是语义检索。结果只会包含标题、简介和截断的页面内容。因此，建议：

- 使用清晰、可检索的标题。
- 把关键结论写在页面开头。
- 将大型主题拆分为多个命名明确的页面。
- 为敏感 Agent 显式绑定最小的文档集合。

## 用于 workflow 检索

workflow 的 **Document Retrieval** / **Wiki retrieval** 节点可选择文档并提供查询问题。运行时会在标题和内容中进行大小写不敏感的包含匹配：

- 默认最多返回 5 条结果，节点界面可配置为 1–20 条。
- 每页返回内容最多 1,200 个字符。
- Document Retrieval 没有指定来源文档时会失败。

在 Try run 中，文档检索会正常执行，因此适合先验证匹配词、返回数量和模板引用。

## 版本、发布与图关联

底层会为每次保存维护页面树、图边和设置的完整版本；编辑草稿会更新草稿，发布后继续编辑会创建新草稿主版本。文档数据也具备图关联、版本读取和发布相关 API。

但当前 Documents 详情页没有版本历史、版本选择、发布、回滚、公开设置或知识图操作面板。用户无法在 UI 中选择旧版本，也无法将当前草稿发布为 release。不要将底层字段（如 `isPublic` 或 `includeInLlmsTxt`）视为已经发布到外部站点的功能。

## 本地存储与安全

所有文档、版本和资源都保存在本机 Electron 用户数据目录中的 SQLite 数据库：`<userData>/workspace/suora.sqlite`。当前没有 Documents 专用加密、用户身份、共享链接、远端同步或自动备份能力。

<Callout type="warning">
  文档内容可能会被 Agent、workflow 和导出文件读取。不要把不应持久保存或不应发送到模型/外部集成的密钥、密码和敏感个人数据写入 Documents。
</Callout>
