## 文档范围

- **用户文档**面向使用者，聚焦模型、Agent、工作流、集成与渠道的操作路径。
- **技术文档**面向贡献者，说明应用架构、数据边界、质量检查与发布流程。

## 推荐阅读路径

如果你是第一次接触 SUORA，建议按以下顺序阅读：

1. **安装与启动**：先准备开发/运行环境，完成第一个模型配置。
2. **Chats / Models / Agents**：了解最基本的对话、模型选择和任务助手配置。
3. **Documents / Skills / Integrations**：补齐知识来源、操作规范与外部能力。
4. **Workflows / Schedulers / Channels**：再进入自动化、定时触发和外部消息接入。

如果你是维护者或准备修改主应用，请优先阅读：

- **应用架构**
- **IPC 通信**
- **SQLite 数据层**
- **测试与发布**
- **安全护栏**
